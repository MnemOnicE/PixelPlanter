### Added

- **Asset Factory**: A new tool to generate sprite sheets of variations with configurable rows, columns, padding, and variance.

## [0.1.0] - 2025-09-15

### Added

- Core `Planter` rendering engine.
- Initial 'Symmetry' generator module.
- Basic palette module for monochrome color schemes.
- `generate()` and `getCanvas()` methods.
- Basic project structure and `package.json`.
